# Knight Game - 2D Platformer

Welcome to **Knight Game**, a 2D platformer where you play as a brave knight navigating through challenging levels filled with obstacles, enemies, and hidden treasures.

## Getting Started

1. **Clone or Download** the repository to your local machine.
2. Open the project in **Unity** (version `2022.3.36 LTS` or higher recommended).
3. Press the **Play** button in the Unity Editor to start playing.

## Game Features

- **2D platformer action**: Jump, fight, and explore a fantasy world.
- **Challenging levels**: Navigate various obstacles, platforms, and enemy types.
- **Combat system**: Use the knight's sword to defeat enemies.
- **Collectibles and Power-ups**: Gather coins, potions, and other items to aid your journey.
- **Boss Fights**: Face off against powerful enemies at the end of certain levels.

## How to Play

1. **Objective**: Reach the end of each level by navigating platforms, defeating enemies, and collecting treasures.
2. **Lives**: You have a limited number of lives. If you lose all your lives, you'll restart the level.
3. **Enemies**: Avoid or defeat enemies using your attack. Some enemies require more hits than others.
4. **Power-ups**: Collect health potions, coins, and other items scattered throughout the level to help you progress.

## Development Notes

- **Unity Version**: This game is built using Unity version `2022.3.36 LTS`. Ensure you're using this or a later version to avoid compatibility issues.
- **Art Assets**: All assets are free-to-use or custom-made.
- **Code Structure**: Scripts are organized under the `Scripts` folder. Major components include:
  - `playermovment.cs`: Handles player movement and actions.
  - `Enemie.cs`: Manages enemy behavior and interaction with the player.
